Task 2 Analysis

1. What is the exact cause of ConcurrentModificationException in Java?

ConcurrentModificationException occurs when a collection is modified while it is being iterated using an Iterator or enhanced for-loop.

Example:
- Removing elements from a List inside a for-each loop
- Adding elements while iterating

Java collections are fail-fast, so they throw ConcurrentModificationException to prevent inconsistent behavior.

3. Provide the minimal code change that resolves this safely.

Use Iterator.remove() instead of removing directly from the collection.

Example:
Iterator<Transaction> iterator = transactions.iterator();

while (iterator.hasNext()) {
    Transaction t = iterator.next();

    if (condition) {
        iterator.remove();
    }
}
